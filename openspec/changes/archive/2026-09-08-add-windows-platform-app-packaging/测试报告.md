## 构建产物

- `release/member-admin/win-unpacked` 与 `LED Game 会员管理端-0.1.0-win.zip`；
- `release/registration-kiosk/win-unpacked` 与 `LED Game 自助注册端-0.1.0-win.zip`。

会员管理端包包含后端 JAR 和 jlink JRE；自助注册端包不包含 JAR、JRE、SQLite 或会员数据。运行时配置、SQLite 和日志均写入各产品自己的 userData，不写安装目录。
