# 2026年11月16日客户输入与便携包反馈

## Why

客户及本机均复现删除精灵后立即新增时名称框无光标、英文数字也不能输入。扩展排查又发现普通编辑器弹窗期间快捷键可删除背后对象、中文组合输入的 Escape 可关闭名称弹窗，以及异步窗口激活可能夺走用户焦点，需要统一修复并增加真实交互回归。

11月17日追加：同机多份游戏端包目前共享 Electron 用户数据目录，不能独立维护游戏数据库和应用配置；资源绝对路径还会使复制后的包继续引用原目录。需要让每份包携带自己的数据、配置及配置资源。

后续明确：重新打包还必须继承旧发行目录已经修改的数据库、配置、资源与硬件配置；授权必须由本机持久保存，不能因重新打包、换包或移动安装目录丢失。

## What Changes

- 将游戏端八个原生确认调用点迁移至应用内异步确认，保留确认内容、取消语义、删除对象无需确认和既有数据写入范围。
- 消除焦点恢复回调无条件移走新输入焦点的问题，新增精灵明确聚焦名称输入框，取消或关闭后尊重用户后来选择的焦点。
- 所有可见模态弹窗期间阻断编辑器底层的删除、移动、切帧、撤销重做及工具快捷键。
- 为精灵、分类、媒体文件夹及同类可达表单增加组合输入期间的 Escape 保护。
- 原生文件对话框返回及 Touch 延迟加载只恢复仍属于当前交互的焦点，不重新激活用户已离开的窗口。
- 增加组件真实渲染、Windows Electron 键盘交互、异步竞态与打包回归，重新交付保持授权加固的游戏端目录包和 ZIP。
- 正式便携包使用 EXE 同级 `data` 目录，数据库、配置、配置资源及相关运行状态随包保存，不依赖启动工作目录。
- 配置选择的应用图标、副屏背景和待机媒体复制到包内，保存相对路径；复制或移动整个包后读取当前副本，保持显式保存及预览语义。
- 提供旧共享数据的停机迁移及升级保留说明，增加两份实际发行包的隔离、重启和移动验收。
- 打包前快照旧发行目录，使用暂存目录完成构建与保护校验，将已保存的数据库、配置、配置资源、媒体和控制器配置带入新目录版及 ZIP；失败和运行中拒绝不得清理原数据。
- 授权保存于当前 Windows 用户的固定本机目录，兼容校验并迁移旧包授权；新 ZIP 不携带授权或会话缓存，同机复用已有有效机器授权，异机仍须通过验签及机器匹配。
- 从分类内点击“游戏 → 首页”明确回到分类卡片首页，即使顶层 section 已是 home；保留普通编辑器返回的分类上下文及未保存离开确认。
- 普通及排行游戏可为独立布线选择每台分控 1、2、4 或 8 路，未设置时沿用包内控制器配置。

## Capabilities

### New Capabilities

- `game-client-dialog-input-safety`：游戏端确认交互、模态键盘隔离、组合输入与异步窗口焦点所有权的统一安全约束。
- `game-client-portable-data`：游戏端便携包独立数据与配置、配置资源复制和整包移动后的路径归属。
- `game-client-machine-activation`：游戏端本机授权跨发行包持久化、旧授权验证迁移及机器绑定边界。

### Modified Capabilities

- `game-client-shell-navigation`：游戏首页入口明确返回分类根页面，重复首页导航也生效。
- `per-game-floor-wiring`：逐游戏保存控制器通道数，并按所选通道数搜索设备和映射输入输出。

## Impact

规划与验收记录位于 `F:/project/ledGame-platform/openspec/changes/client-feedback-2026-11-16`，沿用既有客户反馈 change 的跨仓库组织方式。实现区域为游戏端 `F:/project/ledGame`，以及配套后端 `F:/project/ledGame-backend` 的授权存储兼容迁移；涉及 Vue 交互、Electron 启动目录、配置持久化、打包入口及测试。会员管理端和自助注册端不做变更；数据库结构、授权协议、签名校验及 Electron 大版本保持兼容。
