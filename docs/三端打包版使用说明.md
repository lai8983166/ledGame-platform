# LED Game 三端打包版使用说明

本说明适用于在同一台 Windows 电脑上运行以下三个程序：

| 程序 | 启动文件 | 主要用途 |
| --- | --- | --- |
| 会员管理端 | `LED Game 会员管理端.exe` | 管理会员、手环、积分、房间和业务记录 |
| 自助注册端 | `LED Game 自助注册端.exe` | 顾客注册、查询会员和绑定手环 |
| 游戏端 | `LED Game.exe` | 选择游戏、刷手环、运行游戏和结算积分 |

## 1. 拿到打包版本后怎么使用

1. 如果拿到的是 ZIP，先完整解压，不能直接在压缩包内运行。
2. 三个程序分别放在固定目录中，例如：

   ```text
   D:\LEDGame\member-admin
   D:\LEDGame\registration-kiosk
   D:\LEDGame\game
   ```

3. 必须保留每个 `win-unpacked` 文件夹中的全部文件，不能只复制 EXE。
4. 如果有手环和读卡器，将读卡器插入电脑。读卡器应能在刷手环后输入一串数字并自动回车；没有时可以先跳过。
5. 如果要使用真实地砖，再连接并启动 ELC408 控制器、地砖及相关显示设备。

## 2. 每次启动顺序

### 第一步：启动会员管理端

1. 双击 `LED Game 会员管理端.exe`。
2. 等待本机服务启动完成，不要在提示“等待本机后端连接”时立即操作业务。
3. 使用出厂账号登录：

   ```text
   用户名：admin
   密码：888888
   ```

4. 确认页面数据能够正常加载。

### 第二步：启动自助注册端

1. 双击 `LED Game 自助注册端.exe`。
2. 在店员配置窗口填写：

   ```text
   会员管理端主机：127.0.0.1
   端口：8090
   ```

3. 点击“保存”，再点击“测试连接”。
4. 连接成功后点击“启动自助注册”，进入顾客界面。

### 第三步：启动游戏端

1. 双击 `LED Game.exe`。
2. 进入“配置”，填写会员管理端：

   ```text
   主机：127.0.0.1
   端口：8090
   ```

3. 点击“测试连接”，成功后点击“保存”。
4. 第一次使用或没有手环、读卡器时，建议设置为“触屏启动”；正式使用会员手环时再改为“手环启动”。
5. 没有控制器和地砖时选择“调试模式”；硬件准备完成后再选择“游戏模式”。

关闭时建议先退出游戏端和自助注册端，最后关闭会员管理端。

## 3. 没有手环和读卡器时如何体验

没有手环和读卡器不影响三端启动。第一次体验建议这样设置：

```text
启动方式：触屏
运行模式：调试模式（没有控制器和地砖时）
```

进入游戏后可直接选择人数、游戏和起始关卡，不需要刷手环；调试模式下通过 Debug Panel 模拟踩踏、得分和关卡进度。

此时仍可体验会员管理、会员注册、玩家信息查询、游戏编辑和运营页面，但不能完成手环充值、手环绑定、会员刷卡准入及会员积分结算。准备好手环和读卡器后，再改为“手环启动”并按下面的正式核心流程操作。

如果只有手环和读卡器、但没有控制器和地砖，可以使用“手环启动 + 调试模式”，会员准入和结算仍走正式业务流程，游戏互动由 Debug Panel 模拟。

## 4. 核心营业流程

### 4.1 在会员管理端给手环充值

1. 顾客付款后，店员进入“手环管理”。
2. 点击“手环充值”。
3. 出现“请刷手环”后刷卡。
4. 输入购买分钟数，或选择快捷分钟数。
5. 点击确认充值。

充值成功后，手环处于“已充值待绑定”状态。当前金额按每充值 1 分钟计 1 元。

### 4.2 在自助注册端注册或查询会员

1. 顾客点击“激活手环”。
2. 输入手机号并查询。
3. 已注册会员直接确认资料。
4. 新会员填写姓名、生日和性别，并选择对应性别的头像；使用默认头像时不需要重复选择。

### 4.3 绑定手环

1. 完成会员查询或注册后，进入绑定步骤。
2. 点击刷手环按钮。
3. 弹出“请刷手环”后刷已充值的手环。
4. 成功后提示消失，手环与会员完成绑定。

点击“取消”只会退出刷卡提示，不代表绑定成功。同一只已经绑定的手环不能再次绑定。

### 4.4 启动游戏

1. 在游戏端从待机界面进入游戏配置。
2. 按界面选择游戏、玩家人数、起始关卡等选项。
3. 按提示刷够对应人数的不同会员手环。
4. 手环数量不足、余额不足或状态不允许时，游戏不能启动。
5. 确认配置后开始游戏。

正式游戏由地砖操作驱动；调试模式下使用 Debug Panel 模拟踩踏、得分和关卡进度。两种模式使用相同的底层游戏与结算逻辑。

### 4.5 游戏结束与积分

- 游戏按玩法规则自然完成时，会生成完成记录并为每位玩家结算积分。
- 多人游戏中，每位玩家记录同一局应得积分。
- Debug Panel 的 `End Game` 表示人工中止，记录为 `ABORTED`，不能当作正常完成，积分为 0。
- 会员管理端不会在所有页面自动刷新；游戏结束后可点击“刷新”查看最新积分、记录和手环状态。

### 4.6 排队

当前游戏进行时，可以让下一组玩家选择游戏配置并刷手环加入队列。`READY` 和仍有余额的 `ACTIVE` 手环都可以排队；当前游戏结束后进入下一组游戏。

## 5. 手环状态

| 状态 | 含义 | 可以进行的操作 |
| --- | --- | --- |
| 待充时 `IN_STOCK` | 空闲手环 | 充值 |
| 已充值待绑定 `CHARGED` | 已有分钟数，尚未绑定会员 | 在自助注册端绑定；必要时清除余额 |
| 待游戏 `READY` | 已绑定会员，尚未开始计时 | 在游戏端刷卡；必要时解除绑定 |
| 计时中 `ACTIVE` | 已开始使用，仍有剩余时间 | 继续游戏或排队 |
| 已到期 `EXPIRED` | 可用时间已经耗尽 | 在会员管理端回收后重新充值 |

## 6. 会员管理端有哪些功能

- **运营总览**：查看会员数、今日新增、充值次数、今日收款和房间概况。
- **手环管理**：充值、查看剩余时间、清除未绑定手环余额、解除绑定、回收到期手环和手动刷新。
- **会员管理**：新增、搜索、刷新和查看会员资料、积分、排名及绑定手环；出厂管理员可在满足条件时删除测试会员。
- **房间管理**：查看游戏端是否在线、当前游戏、玩家、队列和剩余游戏时间，并可修改房间名称。
- **积分排行**：查看日榜、月榜和年度榜。
- **记录与数据**：查看发卡记录、游戏记录、交易记录和会员数据，并按日期或关键字筛选。
- **账号管理**：出厂管理员可以建立和管理日常操作账号。
- **设置**：查看本机服务、数据库和日志位置，并修改服务端口。修改端口后，自助注册端和游戏端也要填写相同端口。

## 7. 自助注册端有哪些功能

- **激活手环**：查询或创建会员，再绑定已经充值的手环。
- **玩家信息查询**：按手机号查看注册资料、积分、排名、手环 UID、状态、余额和最近游戏记录。
- **语言切换**：切换界面语言。
- **退出顾客界面**：双击屏幕最左侧隐藏区域，使用软键盘输入维护密码 `888888`，返回店员配置窗口。

自助注册端不能给手环充值，充值必须在会员管理端完成。

## 8. 游戏端有哪些功能

- **正式游戏**：连接真实控制器和地砖运行游戏。
- **调试模式**：无需真实地砖，通过 Debug Panel 模拟游戏输入和流程。
- **多人游戏**：按人数刷入多个不同会员手环，并分别记录积分。
- **游戏排队**：当前游戏运行时预先登记下一组玩家。
- **副屏**：在第二台显示器上显示当前游戏、关卡、积分、生命和剩余游戏时间。
- **游戏管理与编辑器**：维护游戏、关卡、时间、生命、媒体和玩法参数。
- **媒体库与精灵库**：管理玩法使用的图片、GIF、音频和精灵点位。
- **调试助手**：配置 ELC408、搜索控制器、测试点位、发送测试画面和查看报文。
- **语言与连接配置**：切换语言，设置会员管理端地址、启动方式和运行模式。

### 默认游戏硬件配置

游戏端打包版本自带以下 ELC408 默认配置：

- 地砖尺寸：`16×36`
- 布线方式：行蛇形
- SDK 端口：`3003`
- 自动寻找电脑上唯一可用的 `169.254.x.x/16` 网卡

如果提示找不到网卡、存在多个网卡或搜不到控制器，请打开“调试助手”，手动选择连接控制器的网卡，将生成的 `conf.json` 保存到 `LED Game.exe` 同级的 `elc408` 文件夹，然后重新加载运行时。正式游戏前还应确认控制器供电、网线、地砖连接正常，并且 UDP `7800` 未被其他程序占用。

## 9. 常见问题

### 自助注册端或游戏端连接失败

确认会员管理端已经启动并可以加载数据，然后检查两端均填写：

```text
主机：127.0.0.1
端口：8090
```

修改后必须保存并重新测试连接。如果会员管理端修改过端口，以实际端口为准。

### 刷手环没有反应

1. 只在界面明确显示“请刷手环”时刷卡。
2. 用记事本确认读卡器能够输入纯数字 UID 并自动回车，测试后关闭记事本。
3. 确保当前正在操作的程序窗口位于最前面。

### 手环不能充值

- `CHARGED`：已经充值，不能重复充值；未绑定时可以清除余额。
- `READY`：已经绑定；如需作废，先解除绑定。
- `ACTIVE`：正在计时，不能充值或解除绑定。
- `EXPIRED`：先点击“回收手环”，再重新充值。

### 游戏端提示 ELC408 不可用

确认完整复制了游戏端 `win-unpacked`，并保留：

```text
elc408\conf.json
elc408\wiring.json
```

随后检查控制器供电和网线；仍无法使用时，在调试助手中手动选择控制器网卡并重新加载运行时。

### 游戏结束后积分仍为 0

不要使用 Debug Panel 的 `End Game` 作为正常结束。让玩法自然完成，再到会员管理端手动刷新会员、游戏记录或积分排行榜。

### 页面数据没有立即变化

会员、手环、记录和排行榜等页面主要使用手动刷新。完成注册、绑定、游戏或充值后，点击当前页面的“刷新”查看最新数据。

## 10. 数据注意事项

- 会员管理端的 SQLite 保存会员、手环、积分、账号和业务记录，不要随意删除。
- 更新或更换会员管理端前，应先正常退出程序并备份设置页显示的数据库文件。
- 更新游戏端时保留已经确认可用的 `elc408\conf.json` 和 `elc408\wiring.json`。
- 不要在游戏或结算进行中强制关闭会员管理端。
