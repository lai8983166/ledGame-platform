## Purpose

为共用的默认游戏编辑器提供可视化外围符号灯与圆形 RGB 灯布局配置，使布局能够安全预览、校验并保存到现有游戏配置，而不改变当前地砖游戏运行行为。

## ADDED Requirements

### Requirement: 默认游戏编辑器提供布局入口

系统 SHALL 在 `simple`、`normal` 和 `diffcult` 共用的游戏编辑器中提供“符号灯布局”入口，并在独立弹窗中编辑当前游戏的布局配置。

#### Scenario: 打开布局编辑器
- **WHEN** 用户在任一默认玩法编辑器中点击“符号灯布局”
- **THEN** 系统打开布局弹窗并加载当前游戏的 `commonConfig.pixelLightWiring`
- **AND** 三种玩法使用同一套布局编辑行为

#### Scenario: 没有历史布局配置
- **WHEN** 当前游戏没有 `pixelLightWiring` 或缺少部分字段
- **THEN** 系统在编辑态补齐可用默认值
- **AND** 不修改数据库，直到用户明确保存

### Requirement: 布局表单和预览必须是本地草稿

系统 SHALL 支持编辑启用状态、控制器、符号灯通道、圆灯通道、灯链方向、起点、四面墙数量和可选地砖对齐坐标，并根据草稿实时生成预览。

#### Scenario: 绘制预览
- **WHEN** 用户修改表单并点击“绘制”
- **THEN** 系统清理并重绘地砖网格、四面墙、符号灯、圆灯和灯链方向
- **AND** 不发送 HTTP 请求、不发送控制器报文、不写入数据库

#### Scenario: 选择起点
- **WHEN** 用户选择一面墙的起点
- **THEN** 系统只允许该墙 `idx = 0` 的灯作为起点
- **AND** `selectedRow` 只在本地草稿中更新

### Requirement: 布局输入必须经过兼容性校验

系统 SHALL 将界面中的控制器编号和通道编号转换为后端约定的从零开始的值，并拒绝会产生歧义或无法运行的布局输入。

#### Scenario: 转换界面编号
- **WHEN** 用户选择界面显示的控制器 1、符号灯通道 7 和圆灯通道 8
- **THEN** 保存草稿分别使用 `controlIdx = 0`、`pixelPort = 6` 和 `circlePort = 7`

#### Scenario: 重复通道
- **WHEN** 布局处于启用状态且符号灯通道与圆灯通道相同
- **THEN** 系统显示校验错误并阻止保存

#### Scenario: 非法对齐坐标
- **WHEN** 用户输入的非空对齐坐标不符合 `数字,数字` 格式
- **THEN** 系统标记对应输入为无效并阻止保存

### Requirement: 调整墙面数量必须稳定保留已有行配置

系统 SHALL 使用 `wall|idx` 作为墙灯行的稳定身份；调整墙面数量时，仍存在的行必须保留其对齐值，新增行使用空对齐值。

#### Scenario: 墙面数量增加
- **WHEN** 用户增加某面墙的灯数量
- **THEN** 系统为新增索引创建行
- **AND** 新行的 `align` 为空
- **AND** 原有索引行的 `align` 不变

#### Scenario: 墙面数量减少
- **WHEN** 用户减少某面墙的灯数量
- **THEN** 系统移除超出新数量的行
- **AND** 其他墙以及仍存在的索引行保持不变

### Requirement: 保存布局不得破坏现有编辑内容或运行行为

系统 SHALL 将布局保存到现有 `commonConfig.pixelLightWiring`，并在保存失败时保留草稿；关闭布局时不得清空历史数量、起点或对齐数据。本 Change 不得因为布局配置改变当前地砖游戏的运行时输出。

#### Scenario: 成功保存
- **WHEN** 用户提交合法布局并且现有游戏编辑器保存接口成功
- **THEN** 系统持久化 `commonConfig.pixelLightWiring`
- **AND** 重新打开布局时显示刚保存的内容

#### Scenario: 保存失败
- **WHEN** 后端保存请求失败
- **THEN** 系统显示错误并保持布局弹窗打开
- **AND** 当前本地草稿不被清空

#### Scenario: 关闭布局
- **WHEN** 用户将布局设置为关闭并保存
- **THEN** 系统只将 `open` 设为关闭值
- **AND** 已有墙数量、行数据、起点和对齐配置仍然保留

#### Scenario: 现有地砖编辑未保存
- **WHEN** 用户先修改矩阵或关卡但尚未点击外层保存，再保存符号灯布局
- **THEN** 系统只更新持久化布局字段
- **AND** 不覆盖用户当前尚未保存的矩阵或关卡编辑
