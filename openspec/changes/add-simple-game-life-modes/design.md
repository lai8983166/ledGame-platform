# Design

## Context

现有 game 表已有全局生命值字段，运行状态也有整局生命值，但编辑 DTO 未透传，且关卡和整局生命会同时扣减。

## Goals / Non-Goals

仅扩展三个共用编辑器和生命值范围；不新增模式枚举、数据列或硬件抽象，不修改 Rank。

## Decisions

- globalLifeLimit 布尔值就是模式来源，false 为娱乐，true 为闯关；旧 null 视为 false。
- 全局配置提供模式下拉框及闯关总生命输入；娱乐保留关卡生命设置，闯关隐藏关卡生命输入但不清空原设置。
- 新游戏默认娱乐；旧 API 请求未提供字段时保留数据库原值。
- 全局生命启用时关卡限制不参与扣减、显示及失败判定。切换回娱乐后沿用原关卡配置。
- 启用闯关时总生命必须为正整数；关闭时允许保留旧总量以方便再次切换。

## Risks / Trade-offs

旧游戏同时配置两种限制 → 闯关统一以整局限制优先，回归覆盖跨关保留生命及耗尽结束。旧请求遗漏字段 → 映射只在字段非 null 时更新。

## Migration Plan

无表结构迁移；重建游戏端前后端并更新原 release 的 win-unpacked 和 ZIP。若应用正在占用产物则报告阻塞，不强制终止用户程序。
