# 数据库备份与导入

出厂账号登录后，打开“系统设置 → 数据库”。

- **保存备份的路径**：显示自动异盘备份目录。有两块合格物理硬盘时自动选择；只有一块硬盘不影响营业和手动导出。
- **导出数据库**：选择保存位置，生成一个 ZIP，包含一致性数据库、拍照头像和应用图标。无需退出营业，也不要直接复制正在使用的 `platform.db`。
- **导入数据**：选择上述 ZIP（也支持有效的旧 DB 备份），核对版本、最后修改时间、会员数量和出厂账号后确认。当前游戏或排队须先结束。导入覆盖当前数据，失败会回滚；成功后使用备份中的账号密码重新登录。

新版业务数据和备份不加密，妥善保管备份文件；账号密码仍保存为哈希，激活授权不随数据库导出。首次使用新版时会自动解密旧业务数据，旧密钥文件保留用于读取历史备份。缺少原密钥的旧加密备份不能直接导入，新版导出的 ZIP 不需要该密钥。

自动异盘备份、启动检查和正常退出时的收尾备份仍然运行，数据库页面不再列出历史版本或厂家恢复操作。若启动报告数据库身份或版本冲突，不会静默覆盖现有备份，可在出厂账号登录后选择正确备份导入。

身份冲突、版本冲突、导入中或数据库阻断时，关闭应用不会用当前库覆盖备份。自动化测试库不会因持续运行或退出写入正式备份目录。
