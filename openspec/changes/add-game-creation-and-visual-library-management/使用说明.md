# 新建游戏与资源库

## 新建游戏

在“游戏”下拉菜单选择“游戏列表”，点击“新建游戏”。选择娱乐挑战或排位赛，再点击新建，直接进入对应编辑器。多维竞技暂未开放。

此时只是未保存草稿，不生成游戏卡片，也不写入数据库。首次点击编辑器的“保存”并成功后才真正创建游戏；不保存直接返回或关闭则不保留。全局配置、符号灯布局及地砖布线弹窗的保存只修改此草稿，不能代替首次保存游戏。首次保存后才可启动调试，后续保存更新同一个游戏。

- 娱乐挑战：使用 Simple 共用编辑器，默认 16×36 场地、1 人、1 关、1 个空白帧；设置名称、图形、资源和时间后保存。
- 排位赛：使用 Rank 编辑器，默认 16×36 场地、1–6 人、60 秒；修改配置后保存。
- 新游戏不复制或改写已有游戏，保存后在列表中可继续编辑。现有 Simple、Normal、Diffcult 都属于娱乐挑战。

## 精灵库

直接浏览真实颜色的缩略图，点击卡片选中，然后点击“修改”或“删除”。删除仍需确认。“+”可以新增精灵并选择颜色。此修改不影响游戏编辑器中的精灵画笔、宽高筛选和常用精灵。

## 媒体库

先点击文件夹，顶部会显示目标目录；未选择文件夹时上传到媒体库根目录。点击某个文件时，目标目录为该文件所在目录。

- “上传文件”：可多选图片、音频或视频，实际复制进媒体库，刷新后可选择预览；不是引用原文件路径。
- 同名文件自动追加序号，例如 `cover (1).png`，不覆盖原文件。
- “新建文件夹”：在目标目录下创建文件夹；点击“媒体库根目录”可切回根目录。
- 取消选择或取消新建不提交操作；写入失败会显示错误。

媒体仍使用原有应用 media 目录；该目录必须有写入权限。
