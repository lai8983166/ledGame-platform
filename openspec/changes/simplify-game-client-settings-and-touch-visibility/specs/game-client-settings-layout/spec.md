## Purpose

改善游戏端应用配置页的可用宽度与字段对齐方式，让桌面用户更容易读取和修改设置，并在隐藏不常用的端口输入时保持持久化地址、测试连接和已有部署兼容。

## ADDED Requirements

### Requirement: 配置字段横向布局且适应窗口

配置页 SHALL 利用工作区宽度减少两侧无效空白，在桌面窗口将每项标签与控件同行；说明与错误可放在控件下方。窄窗口 SHALL 可换行且无横向页面溢出，不得截断必需控件。

#### Scenario: 常见桌面尺寸
- **WHEN** 用户在 1366×768、1920×1080、2560×1440 打开配置页
- **THEN** 字段标签与输入/选择/资源控件组同行，内容区随宽度展开，按钮与控件不重叠

#### Scenario: 编辑保存与弹窗取消
- **WHEN** 用户修改配置并保存，或选择资源后取消
- **THEN** 原有校验、保存、取消和输入焦点可正常使用，布局不改变保存的业务值

### Requirement: 隐藏端口但连接地址一致

配置页 SHALL 保留会员管理端 IP 输入和测试连接，隐藏端口输入；未配置时 MUST 使用 8090，已有有效自定义端口 SHALL 保留。保存、测试、后台启动与重连 SHALL 使用同一持久化地址。

#### Scenario: 新用户填写 IP
- **WHEN** 新用户填写会员管理端 IP 并测试/保存后重启
- **THEN** 不需要填写端口，测试与后续通信均使用该 IP 和 8090

#### Scenario: 已有非默认端口
- **WHEN** 旧配置使用有效非默认端口，用户保存其他配置或只修改 IP
- **THEN** 非默认端口不被无提示覆盖，测试与通信仍使用相同保存地址
