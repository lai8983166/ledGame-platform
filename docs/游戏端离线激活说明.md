# 游戏端离线激活

游戏端按电脑独立激活，永久有效，不需要联网。会员管理端与游戏端分别授权，两端激活码不能互用。

## 客户操作

1. 打开游戏端，首次未激活时显示软件激活窗口；也可从帮助菜单打开“软件激活”。
2. 复制本机机器码发给厂家。游戏端机器码以`LGG1-`开头。
3. 收到激活码后粘贴或手动输入，点击“激活”。成功后即可正常开始游戏或调试，不会自动开局。

未激活时只显示激活界面，全部业务功能均不可使用，包括导入、导出、编辑、媒体管理、配置及游戏运行。关闭激活界面将退出软件；激活成功后才开放主界面。启动查询完成后显示实际状态，不提供重试按钮。激活码输入错误时更正后再次激活，不要删除数据库。

升级软件、更改端口或导入游戏不影响授权。同一Windows系统重新安装软件、授权文件丢失后可重新输入原激活码；重装Windows或换电脑可能需要重新向厂家申请。当前不设置到期、次数额度或自动转移。

## 厂家签发

使用原`release/activation-signer`内的激活码签发工具，选择原厂家私钥、粘贴客户机器码、生成并复制激活码。工具根据机器码自动显示“游戏端”或“会员管理端”：`LGG1-`对应游戏端，`LGM1-`对应会员管理端，不需要另选产品。更改机器码后旧结果会清空，需重新生成。

命令行仍为`node scripts/activation-tool.mjs issue <私钥路径> <机器码>`，自动识别产品。不要重新生成密钥来替换现有厂家密钥，私钥不得提供给客户或放入游戏安装包。

## 数据保存

游戏端授权保存在本机用户数据目录的`activation/license.json`，与游戏数据库分开，不随游戏导入导出或数据库更新覆盖。复制游戏数据库到另一台电脑不能代替该电脑的激活。

机器码来自Windows系统身份摘要，不使用IP、端口或网卡地址。后台会在实际运行前检查授权，界面入口之外的启动请求同样受限。客户包仅内置厂家公钥，不提供跳过激活或替换信任公钥的设置。
