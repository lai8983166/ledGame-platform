# Proposal

## Why

会员管理端不再需要业务数据加密及复杂的数据库维护页面。需要在不损失已有数据、不取消自动异盘备份的前提下，提供直观的全量备份与导入。

## What Changes

- 业务字段和拍照头像以明文保存；启动时安全迁移已有加密数据，账号密码哈希与激活授权不变。
- 数据库页仅保留备份保存路径、导出数据库、导入数据；取消候选版本列表、厂家恢复及密钥操作的页面入口。
- 手动导出为包含一致性 SQLite 快照、头像及校验元数据的 ZIP，保存位置由用户选择；导入前验证并确认覆盖，保留失败回滚及重新登录机制。
- 自动异盘备份、启动检查、正常退出收尾备份和测试环境隔离保留。旧加密备份仍可在密钥可用时导入，不可解密时明确拒绝而不损坏原数据。

## Capabilities

### New Capabilities

- `member-admin-plaintext-storage`: 明文业务数据及旧数据迁移。
- `manual-full-database-backup`: 精简数据库页面与可验证的全量备份、导入。

### Modified Capabilities

无。本次取代历史 Change 中的加密存储要求；主规格目录尚未包含对应能力。

## Impact

仅修改 ledGame-platform 的会员管理端、托管后端、Electron 文件选择与数据库导入链路、相关测试和中文说明。自助注册端、游戏端接口和业务语义保持不变，不变更账号权限，不操作开发机实际数据。
