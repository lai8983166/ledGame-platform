# 门店局域网配置与冒烟说明

## 1. 启动会员管理端

在承担服务器职责的 Windows 电脑上启动会员管理端，先登录，再等待设置页显示“本机服务运行正常”。新数据库的默认出厂账号为 `admin`，密码为 `888888`；门店正式使用前应由出厂管理员创建日常操作员账号。产品没有密码找回入口，出厂账号遗失时需联系厂家处理。默认服务端口是 `8090`。

设置页会列出类似下面的地址：

```text
http://192.168.1.10:8090
```

选择与门店其他机器处于同一网段的非回环 IPv4。不要把 `127.0.0.1` 填给其他电脑；它只代表各自本机。

## 2. 配置自助注册端

启动自助注册端后，首先出现店员启动页：

1. 填写会员管理端的 IP 或主机名；
2. 填写会员管理端端口；
3. 点击“保存配置”；
4. 点击“测试连接”；
5. 只有测试成功后才能点击“启动自助注册”。

顾客流程在独立全屏窗口中运行，不会显示管理端 IP。普通关闭操作会被拦截；店员按 `Ctrl + Shift + F12` 可退出顾客窗口并恢复启动页。

若运行中断线，顾客窗口会遮罩业务操作并定时重连。恢复连接后回到安全首页重新办理，不继续提交断线前的半完成会话。

## 3. 配置游戏端

在每台游戏端的 Tab 配置中填写同一个会员管理端 IP 与端口。会员管理端不需要预先知道自助注册端或游戏端的 IP；这些终端是主动连接方。

## 4. Windows 防火墙与路由器

- 会员管理端后端监听所有本机网络接口，但只需在 Windows 防火墙中允许所配置的 TCP 端口进入；
- 建议在路由器 DHCP 中为会员管理端做地址保留，避免重启后 IP 改变；
- 不要随意把机器设置到路由器网段之外；优先使用 DHCP 或与路由器网段一致的静态地址；
- 自助注册端和游戏端通常不需要开放平台服务入站端口。

## 5. 跨机冒烟清单

在真实门店网络至少完成一次：

1. 使用出厂管理员登录，创建一个普通操作员，并验证退出或重启后需要重新登录；
2. 使用普通操作员登录，确认日常办理入口可用，会员删除、主动清空余额、房间改名和系统设置入口不可见；
3. 自助注册端测试连接成功并启动顾客窗口；
4. 会员管理端为真实读卡器输入的手环 UID 充时；
5. 自助注册端注册或查询会员，刷同一手环并绑定；
6. 游戏端刷卡进入游戏，完成一次游戏与一次排队切换；
7. 三端核对会员、手环余额、积分、房间状态和游戏记录；
8. 分别重启自助注册端和游戏端，确认会从各自持久化配置自动重新连接；
9. 临时断开网络并恢复，确认不会产生重复绑定、重复结算或卡死；
10. 关闭会员管理端，确认其 Java 子进程和端口均被释放。

这里的操作账号是可信局域网中的轻量界面权限和留痕机制，不应作为把平台直接暴露到互联网的安全措施。普通覆盖安装会保留会员管理端 userData 中的 SQLite 和已有账号；恢复出厂若删除数据库，则会同时删除全部业务与账号数据。

自动化集成测试能覆盖软件契约，但不能代替现场对 USB 读卡器、路由器、防火墙、控制器、地砖、显示器和断电恢复的最终确认。
