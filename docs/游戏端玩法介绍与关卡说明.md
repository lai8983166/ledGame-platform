# 游戏端玩法介绍与关卡说明

适用于Simple、Normal、Diffcult共用编辑器。

## 配置位置

- 全局配置中的“玩法介绍”：选择整个游戏的教学视频。
- 关卡背景音乐下方依次为“玩法介绍”“语音说明”“游戏说明”：分别选择本关教学视频、录制好的说明音频，以及填写本关文字。
- 都是可选项，沿用原来的保存和取消流程。全局保存不会提前保存未提交的关卡内容，关卡JSON导入导出保留这些字段。

关卡背景音乐、玩法介绍、语音说明及全局玩法介绍使用方形资源按钮：空值点击中央加号选择资源；已有资源显示播放标志和名字，点击打开预览窗口，右上圆形叉号清除。关闭预览、切关或更换资源会停止播放，清除仍需按原保存流程生效。

文字不会自动生成语音，也不新增旧版未找到的关卡文字运行展示。玩家选关界面的整局“描述”仍按原流程展示，与本关“游戏说明”分开。

## 播放方式

- 玩家选关时可以点击全局“玩法介绍”或关卡旁的播放按钮，打开静音循环视频，关闭后返回当前选择。
- 整局开始说明音频播放期间，玩家端及副屏同步显示全局教学视频；视频静音循环，说明结束后隐藏。
- 本关321结束后，发起本关语音及教学视频，然后播放原关卡开场GIF并进入玩法，不等待本关语音讲完。语音可以跨入玩法继续讲解，视频随语音结束隐藏。
- 关卡视频的自动播放依赖本关语音说明；只选择视频时仍可在选关界面手动观看。
- 本关语音播放时背景音乐降低至约20%，结束或停止后恢复。普通失败重试不重复讲解；手动重开或切关后可以再次讲解。
- 暂停、恢复、停止和切关统一清理或同步音视频，视频播放结束不会自行推进游戏。可选资源缺失或损坏沿原媒体诊断处理，不因教学视频无法播放而卡住游戏。

布线面板按最大点数顺序自动分配通道，不再提供手动增加或删除末尾空通道按钮；通道列表、已有布线及导入导出保留。
