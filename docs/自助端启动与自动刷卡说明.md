# 自助端启动与自动刷卡

- 店员页填写会员管理端地址和端口，直接点击“启动自助注册”。配置自动保存，检查成功后打开顾客窗口；失败关闭提示后修改或重试。退出顾客窗口后仍可再次启动。
- 激活：输入手机号 → 确认已有会员或完成注册 → 直接等待刷手环。读卡器输入数字并回车后提交；不再有“开始刷卡”按钮。
- 查询：进入查询 → 切换手环查询 → 直接刷卡。无需输入框和软键盘；结果仍为只读。手机号查询保留。
- 取消刷卡：激活回会员资料确认，查询回手机号查询。超时或连接中断回首页，恢复后重新办理。不会把取消当成成功，不会删除已经注册的会员。

取消尚未提交的等待不会激活。若绑定请求已经发出，取消或网络超时不能撤销服务端已成功的绑定；再次扫描已绑定卡仍提示“此手环已绑定”，不会重复入账或重置计时。

## 自动化验证

开发双窗口与模拟服务的异常流程：`pnpm test:desktop:electron`。

打包后复用同一套流程（Git Bash）：

```bash
LEDGAME_TEST_PACKAGED_KIOSK=1 pnpm exec playwright test desktop/tests/registration-kiosk.electron.spec.mjs --workers=1
```

测试覆盖失败启动、重试、配置记忆、退出再启动、新老会员自动等刷卡、取消、重复输入、超时、迟到响应、断线恢复和只读查询，使用临时目录与模拟服务，不接触日常数据库。另由 `member-admin.allocation.electron.spec.mjs` 对两端打包版和临时真实数据库验证预充值、激活、计时及积分/等级查询。
