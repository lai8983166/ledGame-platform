## Why

游戏端仍有重复的标题副文案、过窄的配置/调试操作区和不再需要的硬件配置入口，增加操作负担。游戏的显示开关也不应继续依赖会员管理端的门店儿童模式，应由游戏端独立决定触屏可选游戏。

## What Changes

1. 移除游戏端所有大标题旁的装饰性副标题，包括 `Game List` 等英文对照标题；保留主标题、字段标签、错误提示与必要业务信息。
2. 配置页隐藏会员管理端端口输入，未配置时使用既有默认 8090，保留 IP 编辑、保存、测试连接与重连。
3. 配置页利用更多可用宽度，每项标签与控件横向同行；提示/错误可置于控件下方，窄窗口允许自然换行。
4. 布线方式中文显示改为“单行 / 单列 / 折返行 / 折返列”；只改文本，不改变枚举、坐标、方向或生成的布线。
5. 调试助手移除“配置”子 Tab，保留布线工具和调试工具；新默认配置、调试草稿的灯具线序改为 GRB，保留已保存的显式线序配置。
6. 调试工具扩大左侧操作台、缩小右侧日志区，标签与控件同行；保留日志内容、展开、轮询和清除功能。
7. **BREAKING（行为变更）**：“儿童模式下可见”改为“触屏显示”，逐游戏开关独立保存后立即影响触屏可选列表，不再由会员管理端儿童模式开关控制。管理列表始终可找到关闭显示的游戏，进行中的游戏不被强制结束。

## Capabilities

### New Capabilities

- `game-client-heading-presentation`: 游戏端主标题精简及装饰性副标题移除边界。
- `game-client-settings-layout`: 配置页宽度、横向字段与隐藏的会员管理端端口。
- `game-hardware-assistant-operation`: 硬件助手入口、布线文本、GRB 默认值与调试/日志布局。
- `game-touch-catalog-visibility`: 游戏端独立的触屏显示配置、立即刷新和运行保护。

### Modified Capabilities

无。当前 `openspec/specs` 中尚无这四项能力。本 Change 明确替代已完成但未同步到主规格的 `add-configurable-child-mode-game-visibility` 中“受会员管理端总开关控制”的游戏端行为；不修改旧 Change 的历史记录，也不删除会员管理端功能页或旧客户端协议。

## Impact

- 规划统一位于本仓库；实施涉及 `F:/project/ledGame` 及必要的 `F:/project/ledGame-backend`。
- 前端：主页面/编辑器/弹窗标题、`ApplicationSettingsView`、`Elc408DebugAssistantView`、布线/调试面板、`GameInfoEditDialog`、`GameListView`、`LedGameTouchView`、本地化、样式、Electron 配置/IPC 与打包默认配置生成脚本。
- 后端：可玩目录过滤、启动校验中遗留门店儿童模式依赖与配置缺省线序；元数据保存成功后的跨窗口刷新复用 Electron IPC。保留现有字段与接口，不新增表或通用可见性框架。
- 新游戏端不再受会员管理端 `childMode` 消息影响；房间连接、硬件状态、会员刷卡、扣时、积分与记录通信保持不变，旧游戏端不改。
- 配套前后端测试、真实界面布局/交互检查和游戏端打包版隔离冒烟；实施完成后只更新游戏端 `win-unpacked` 和 ZIP。
- 非目标：不调整游戏玩法/积分/扣时，不修改 SDK 报文算法、不删除日志证据、不升级多语言架构、不删除现有资源或人工数据库。
