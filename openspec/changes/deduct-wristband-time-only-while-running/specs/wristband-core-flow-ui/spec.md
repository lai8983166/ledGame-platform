## ADDED Requirements

### Requirement: 手环界面按实际游戏时间展示余额
会员管理端和自助注册端 SHALL 将手环时间表述为“剩余游戏时长”，并 SHALL NOT 暗示刷卡、配置或等待会持续消耗余额。

#### Scenario: 查看待游戏手环
- **WHEN** 店员或会员查看一只 `READY` 手环
- **THEN** 页面显示持久化的剩余游戏时长
- **AND** 页面说明仅游戏实际运行期间消耗

#### Scenario: 查看游戏中手环
- **WHEN** 店员查看一只存在未结算 play 的 `ACTIVE` 手环
- **THEN** 页面显示“游戏中”以及最近一次提交的权威余额
- **AND** 页面不得将本地页面倒计时冒充已经完成的数据库扣减

#### Scenario: 游戏结束后手动刷新
- **WHEN** 游戏结果已经结算且店员刷新手环或会员列表
- **THEN** 页面显示扣除本局实际 `RUNNING` 时长后的余额和最终状态
