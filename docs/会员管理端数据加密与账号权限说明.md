# 会员管理端数据加密与账号权限说明

## 本机数据保护

会员手机号、姓名、头像标识、生日、性别、手环 UID、充值记录中的手环 UID、游玩记录中的手环 UID 和结果详情，以及操作日志中的账号快照、目标和摘要，均以 AES-256-GCM 密文写入 SQLite。手机号和手环 UID 的精确查询使用独立的 HMAC-SHA-256 摘要，不使用可逆密文做索引。

数据密钥由 Windows DPAPI CurrentUser 保护，保存在会员管理端用户数据目录的 `security\data-key.dpapi`。开发桌面版和打包版继续共享同一 Windows 用户数据目录和同一密钥；自动化测试使用隔离的临时密钥与数据库。

请勿单独删除或替换 `platform.db`、`data-key.dpapi`、WAL/SHM 或备份元数据。数据库已加密但密钥缺失、不匹配，或者密文被篡改时，后端会阻断业务写入并在启动维护界面显示明确错误，不会创建空数据库覆盖原数据。

当前自动恢复范围仅限同一台 Windows、同一个 Windows 用户。更换电脑、重装 Windows 或更换 Windows 用户后，DPAPI 信封通常无法解封；此类跨环境恢复不在当前功能范围内，必须联系厂家处理。

## 账号权限

| 功能 | 出厂管理员 | 店长 | 店员 |
| --- | --- | --- | --- |
| 手环充值、清零、回收、解绑 | 可用 | 可用 | 可用 |
| 会员查询和新增 | 可用 | 可用 | 可用 |
| 删除会员 | 可用 | 不可用 | 不可用 |
| 运营总览、房间、记录、排行榜 | 可查看 | 可查看 | 不可查看 |
| 儿童模式等功能开关 | 可用 | 可用 | 可用 |
| 导出会员、交易、游玩 CSV | 可用 | 可用 | 不可用 |
| 管理店员账号 | 可用 | 可用 | 不可用 |
| 管理店长账号 | 可用 | 不可用 | 不可用 |
| 数据库导入、备份维护和服务配置 | 可用 | 不可用 | 不可用 |
| 修改本人密码 | 可用 | 可用 | 可用 |

出厂管理员账号不可停用或删除。账号删除采用逻辑删除：账号立即失去登录和操作权限，但历史操作日志仍保留。停用、删除或不存在的账号继续发起请求时，管理端会清除失效登录状态；普通越权请求只提示权限不足，不会误报为网络故障。

## 导出数据

会员、交易和游玩数据的导出入口统一位于“记录与数据”页，仅出厂管理员和店长可见。导出文件由后端解密后直接交给桌面端，并由用户手动选择保存位置。

CSV 是为了查阅和交接而主动生成的明文文件，不是加密备份。导出后应由门店自行控制保存位置和传输范围。系统的异盘 SQLite 备份仍保存密文字段，并携带 DPAPI 密钥信封和 `keyId` 元数据。
