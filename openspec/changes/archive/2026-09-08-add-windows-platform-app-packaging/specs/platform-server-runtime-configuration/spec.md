## ADDED Requirements

### Requirement: 会员管理后端端口在启动前配置
会员管理端桌面应用 SHALL 从本机持久化配置读取后端监听端口，缺省使用 `8090`，并通过显式启动参数传递给 Spring Boot 后端。

#### Scenario: 首次启动使用默认端口
- **WHEN** 本机尚未保存会员管理后端端口配置且 `8090` 可用
- **THEN** 应用在 `8090` 启动后端
- **AND** 会员管理 UI 通过 `127.0.0.1:8090` 访问本机后端

#### Scenario: 使用已保存端口启动
- **WHEN** 本机已保存一个合法端口且该端口可用
- **THEN** 应用使用该端口启动后端
- **AND** 会员管理 UI 与对外连接信息均显示实际端口

### Requirement: 端口修改经过校验并重启生效
系统 SHALL 只接受 `1..65535` 范围内且当前可绑定的端口；修改端口 SHALL 保存配置并在受管后端重启后生效，不得宣称运行中热切换成功。

#### Scenario: 保存新端口并重启后端
- **WHEN** 操作员输入一个可用的新端口并确认应用重启后端
- **THEN** 旧后端被有序停止，新后端使用新端口启动
- **AND** UI 只有在新端口健康检查成功后才恢复业务操作

#### Scenario: 端口非法或已被占用
- **WHEN** 操作员输入越界端口或所选端口已被其他进程占用
- **THEN** 系统拒绝保存或启动并显示明确原因
- **AND** 不随机选择另一个端口，也不破坏上一次合法配置和 SQLite 数据

### Requirement: 监听地址由应用控制
会员管理后端 SHALL 监听 Windows 提供的局域网接口，操作员不得在 UI 中设置或伪造本机监听 IP；会员管理 UI 自身 SHALL 始终通过回环地址访问本机后端。

#### Scenario: 展示局域网访问地址
- **WHEN** 后端健康且 Windows 存在一个或多个非回环 IPv4 地址
- **THEN** 会员管理端展示每个候选 `IPv4:端口` 供其他终端填写
- **AND** 展示行为不修改 DHCP、静态 IP、路由器或 Windows 网卡配置

#### Scenario: 本机网络地址变化
- **WHEN** Windows 网络接口变化导致局域网 IPv4 地址改变
- **THEN** 会员管理端刷新展示的候选连接地址
- **AND** 后端端口配置保持不变

### Requirement: 后端使用稳定的应用数据路径
桌面应用 SHALL 以绝对路径向后端传入 SQLite 和日志位置，并确保路径位于应用用户数据目录而非当前工作目录或安装资源目录。

#### Scenario: 从不同工作目录启动
- **WHEN** 会员管理端从快捷方式、命令行或解压目录中的不同当前工作目录启动
- **THEN** 后端仍打开同一个受管 SQLite 数据库和日志目录
- **AND** 不在随机当前目录创建新的 `platform.db`
