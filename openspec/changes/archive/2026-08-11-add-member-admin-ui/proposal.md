## Why

现有 `member-admin` 仅有占位入口，无法承载门店日常的房间监控、会员维护、记录查询和运营数据查看。需要先建立一套层次清晰、操作简单的完整管理端 UI，为后续接口与硬件对接提供稳定的页面和交互基线。

## What Changes

- 为 `member-admin` 建立“总览、房间、会员、记录、排行、系统设置”六个一级入口，采用明亮的液态玻璃拟态视觉体系，并兼顾常见桌面管理屏幕与窄屏布局。
- 新增运营总览 UI，展示总会员数、当日新增会员、发卡次数、收款金额及房间实时概况。
- 新增房间管理 UI，支持展示与编辑房间名称，区分空闲、游戏中和结束倒计时状态，并查看实时积分、实时排名、游戏状态及硬件临时状态。
- 新增会员管理 UI，支持会员列表查询、新增、编辑、删除确认、详情查看和充值弹窗；会员资料覆盖账号、头像、联系方式、充值金额、手环时长与身份 ID。
- 新增记录与数据 UI，分别承载发卡记录、游玩记录、交易记录、会员数据和游戏数据，并提供面向展示数据的搜索、筛选、分页和详情交互。
- 新增副屏排行 UI，可在日榜、月榜、年榜间切换，并提供适用于电视副屏的预览/展示模式。
- 新增系统设置 UI，集中设置 IC 手环有效使用时长、各类功能开关和数据上传目标；明确提示手环游戏时长从游戏系统首次刷卡后开始计算，未开始游戏不生效。
- 数据上传区域展示联网状态、目标类型（邮箱或服务器）、目标地址、自动上传开关、最近上传结果及测试操作。
- 本 change **仅实现 UI**：使用本地模拟数据和前端状态完成页面展示、表单校验、筛选切换与反馈，不实现真实持久化、会员资金交易、硬件通信、电视连接、邮件发送或服务器上传。

## Capabilities

### New Capabilities

- `member-admin-ui`: 会员管理端的完整 UI 信息架构、运营总览、房间监控、会员操作、记录与统计、排行榜和系统设置交互。

### Modified Capabilities

- 无。

## Impact

- 主要影响 `apps/member-admin` 的 Vue 页面结构、样式、静态资源与前端模拟数据。
- 可能复用或扩展 `packages/shared-ui` 中的通用展示组件，但不要求更改服务端 API。
- 不新增真实外部系统依赖；硬件、支付、电视副屏、邮箱和服务器上传均以 UI 状态和模拟反馈表达。
