# Proposal

## Why

Simple 共用编辑器的操作分散在对象面板和右侧栏中，重复按钮、颜色反馈和手动层级/基准点操作增加了使用负担。同色点位可以无限叠加，需要收紧编辑约束，同时保持现有玩法、颜色叠加规则与旧游戏数据可用。

## What Changes

- 隐藏复制当前帧到前一帧、末尾添加帧按钮，保留添加帧到后一帧及其他需要的帧操作；隐藏不等于删除实现。
- 对象操作与原右侧保存游戏、启动调试、预览、导出等操作集中到帧序列下方的一行工具栏；删除右侧静态信息栏，保留必要的错误和进度反馈。
- 普通操作使用可识别的图标及悬浮说明；复制重复次数保留为文字按钮。同颜色复制到全帧的四宫格图标使用实心方块。
- 对象按钮不再有改变颜色的 hover 效果，保留清晰的选中、禁用与键盘焦点状态；颜色 3 的“粉色”文本改为“紫色”，不修改颜色数据。
- 删除对象无需二次确认，仍可通过现有撤销恢复；不取消删除帧/关卡、覆盖帧的确认。
- 隐藏手动修改基准点、层级调整、改色、复制选中对象到前/后/全帧按钮，保留实现。基准点自动取对象占用范围的整数中心，形状变化后自动重算且不改变实际点位。
- 每个 RGB 坐标每种颜色最多占一层，最多四种颜色；不同颜色允许叠加，保持现有覆盖优先级。同色重复绘制静默跳过，不增加层、不显示拒绝或错误提示；不能只限制层数显示。
- 限制覆盖绘制、精灵、移动、旋转、复制、导入、特效等修改路径；旧游戏不在读取时删除点位，保留兼容读取及修复能力。
- Simple、Normal、Diffcult 共用上述编辑器，因此三种玩法一起适配；Rank 编辑器及正常游戏流程不改。
- 追加：移除新增/选择移动和独立精灵画笔入口。点击已有对象选择；拖动起点有对象则移动，空白起点且选中单色画笔才框选。四色画笔移回对象编辑区，选中精灵卡片直接用于单击放置且与单色互斥。空搜索显示固定常用精灵，预览每格固定正方形、图形容器按宽高自适应。
- 追加：关卡通过/重启语音、关卡结算/失败动画从全局配置移至左侧基础信息，保留所有关卡共用的数据语义，随保存游戏持久化；全局配置不再覆盖这四项草稿。

## Capabilities

### New Capabilities

- `simple-editor-toolbar-simplification`: 帧下方统一工具栏、隐藏操作、按钮呈现及安全反馈。
- `simple-editor-bounded-color-overlap`: 按坐标和颜色限制新叠层、静默跳过同色重复、旧数据兼容。
- `simple-editor-centered-object-anchor`: 自动中心基准点及保持绝对点位的重基准处理。

### Modified Capabilities

无。规划所在仓库的主规范尚未包含编辑器能力；游戏仓库既有对象编辑、帧安全和编辑历史规范作为兼容背景，本 Change 明确变更其中对应的界面行为，不改变其他约束。

## Impact

- 游戏前端 `F:/project/ledGame`：`SimpleGameEditorView.vue`、`SimpleMatrixCanvas.vue`、`EditorSpritePreview.vue`、固定精灵目录、对象/占用与历史辅助逻辑、`EditorActionIcon.vue`、样式、语言文本、单元和真实组件交互测试。
- `F:/project/ledGame-platform`：本 Change 的 proposal、design、specs、tasks 及后续验证记录。
- 不新增数据库字段、后端接口、按钮权限框架或通用绘图引擎；不改变保存结构、硬件输出、颜色优先级、会员积分、布线和符号灯逻辑。
- 实施完成后重新打包游戏端原位置的 `win-unpacked` 和 ZIP，不重打其他端。
