# 编辑器单页调试与逐游戏布线验证记录

验证日期：2026-10-07。产品修改涉及游戏前端和游戏后端；会员管理端、自助注册端产品代码未修改。

## 已验证的功能

- Simple、Normal、Diffcult 共用编辑器与 Rank 编辑器进入主窗口调试页，不创建 Touch/DebugPanel；未保存内容提供保存、使用已保存版本、取消三种选择，返回保留草稿。
- 直接启动不依赖会员平台。手环启动使用原准备/准入接口，接受数字 UID＋回车，人数不足、重复卡、平台错误不会被当作成功。普通数字输入不会被读卡监听吞掉。
- 真实暂停覆盖 STARTING/RUNNING/SETTLING：游戏/关卡时钟、帧、Rank 效果、音频和地砖动画停止推进；暂停输入丢弃，迟到媒体回调不推进旧会话。购买余额仍遵循原会员平台规则，不宣称暂停免扣费。
- 重新开始正常终止旧局、建立新会话，手环需重新扫描准入；退出确认清理后返回。自然结算留在调试页，两名测试会员分别收到积分。
- 游戏 A/B 独立布线持久化、导入导出、旧数据回退、尺寸/容量/重复/越界校验。启动固定快照，输出和踩踏使用同一映射；结束恢复全局布线。配置失败关闭错误硬件输出，模拟调试仍可运行。

这些用例分别覆盖编辑器多人准入/重开/自然结算/返回、正常触屏手环与排队、PRODUCTION 软件形态下真实 TCP 输入、主动中止零积分、离线 outbox 补传及重复结算。报告生成在 `acceptance/artifacts/测试报告.md`。PRODUCTION 用例使用模拟 TCP 设备，不是实际地砖验收。

测试等待使用实际窗口 URL 和调试页卸载，不以窗口总数或同名按钮判断跳转完成；Rank 启动等待包含现有语音/动画耗时，不能把普通按钮的 15 秒等待当作媒体时限。

烤机模拟采集器原来只认识 16×16 待机帧，在未选游戏的 PREPARING 阶段误报现有 16×36 彩虹帧。补正只将 IDLE/PREPARING/STOPPED 下的 16×36 帧计为过渡证据，不计入 RUNNING 帧。新测试仍要求运行中错误尺寸被拒绝，不放宽稳定游玩帧校验。

最新真实 EXE 短循环回归：两局自然结束，累计 RUNNING 120.015 秒；模拟采集有效帧 5449、RUNNING 帧 4569、拒绝帧 0，残留缓存 0。主库副本/EXE/资源哈希复核通过。这是入口和帧链路冒烟，不是长时间稳定性验收。修正后的便携烤机工具已更新到 `release/game-soak`。

Rank 调试页采用玩法快照的 `remainingMillis`；额外全局限时存在时取两者更短者。组件测试覆盖“未开额外全局限时仍显示 Rank 倒计时”，真实联调核对暂停后的数值与后端一致。
