# 会员等级管理

1. 出厂账号或店长进入“系统设置 → 等级管理”，新增等级名称、最低排名积分、最高排名积分。
2. 积分范围两端都包含。例如“入门 0–999”“进阶 1000–4999”，不能把后一等级设成从 999 开始。名称不能重复，范围不得重叠；允许空档。
3. 可编辑已有等级；只有出厂账号能确认删除等级，取消不删除。
4. 会员列表、详情及自助查询显示按排名积分匹配的等级；无匹配或尚未配置时显示“未定级”。配置修改后重新查询/刷新即可看到。

兑换只扣剩余积分，不会降级。新游戏正常结算后，排名积分达到另一区间就显示对应等级。没有手动定级、等级优惠或预设门店等级。

店员只能查看会员等级，不能配置。改等级不会修改会员、积分、账户时长、游戏记录或排行榜；等级配置随数据库全量及自动备份保存。

## 接口

- `GET /api/member-levels`：已登录操作员查看配置。
- `POST /api/member-levels`：新增，提交 `name`、`minPoints`、`maxPoints`。
- `PUT /api/member-levels/{id}`：修改同样三个字段。
- `DELETE /api/member-levels/{id}`：删除配置，仅出厂账号。
- `GET /api/members` 新增可空 `levelName`；Player Info 新增可空 `profile.levelName`。旧积分字段不变，新前端连接旧响应时显示未定级。

配置接口使用现有 `X-Operator-Id`。名称 1–30 字，积分是 0–9007199254740991 的整数；上下限校验、重叠校验和写入在事务内处理，并发也不得产生相交区间。新增、修改、删除沿用现有操作员审计记录。
