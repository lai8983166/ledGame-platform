# 会员发卡与还卡验证记录

日期：2026-10-14。

## 已完成

- 柜台业务位于运营管理首页，只保留发卡、还卡两个主按钮；独立手环导航及清余额、解绑、回收入口不再展示。
- 可用秒数归会员账户。发卡不扣时，首次游戏刷卡激活后沿用持续计时，还卡结算剩余并暂停；换卡不复制或丢失余额。
- 发卡重试幂等、运行中还卡拒绝、迟到还卡不释放新持有人；失败时充值与绑定一起回滚。
- 旧 READY/ACTIVE 剩余时长一次迁移，历史不重新加回；旧 charge/bind 与旧游戏通信接口保留。
- 充值记录明确关联会员；发卡记录不再使用下一位持卡人的充值时间。
- 自助查询即使已还卡仍显示独立账户余额；会员资料编辑、历史查询、取消弹窗后的输入均已验证。
