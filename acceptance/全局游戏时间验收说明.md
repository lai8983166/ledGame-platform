# 全局游戏时间验收说明

## 验收口径

副屏和会员管理端房间管理显示的是“本局全局游戏时间”，不是会员手环的可用余额。手环余额用于判断会员能否进入游戏；全局游戏时间来自当前玩法的游戏配置，控制这一局还能运行多久。

- 配置有限全局时间时，副屏、房间卡片和房间详情显示实时倒计时。
- 游戏进入结算等暂停阶段时，显示值冻结；恢复下一关后继续倒数。
- 未配置有限全局时间时显示“无限”，不得使用 `00:00` 冒充无限。
- 游戏空闲或结束后隐藏；旧游戏端没有 `gameTime` 字段时显示 `--`。
- 不足一秒按一秒显示；不足一小时使用 `MM:SS`，一小时及以上使用 `HH:MM:SS`。

## 自动化测试命令

在三个仓库分别运行：

```powershell
cd F:\project\ledGame-backend
mvn test

cd F:\project\ledGame
pnpm test
pnpm build

cd F:\project\ledGame-platform
pnpm test:server
pnpm test:client
pnpm test:acceptance:unit
pnpm typecheck:member-admin
pnpm build:member-admin
```

其中 `acceptance/fixtures/game-time-contract.json` 是跨仓库契约样例，覆盖有限自然倒数、结算暂停、恢复下一关、无限时间、运行中重连、旧快照兼容和手动结束。

## 手动核对步骤

1. 启动会员管理端、一个游戏端主屏和副屏，使游戏端连入会员管理端。
2. 选择一个配置了有限全局时间的玩法并开始游戏，确认副屏、房间卡片和房间详情显示语义一致，允许存在网络传输和界面 tick 造成的约一秒差异。
3. 进入结算阶段并停留数秒，确认两个界面的数值都冻结；恢复下一关后确认继续倒数。
4. 在游戏运行中重启游戏端或断开再恢复平台连接，确认重连快照恢复正确的有限/无限模式和剩余时间。
5. 手动结束游戏，确认副屏和房间管理不再显示本局剩余时间。
6. 启动一个未配置有限全局时间的玩法，确认两个界面均显示“无限”。
7. 对照会员的手环余额，确认它与本局全局游戏时间是两个独立数值，不因本功能而混用。

## 报告

运行 `pnpm test:acceptance` 后生成的中文摘要仍位于 `acceptance/artifacts/测试报告.md`。报告中的全局游戏时间口径应按本说明解释；真实控制器、地砖、多机局域网和物理断线仍需现场冒烟验收。
