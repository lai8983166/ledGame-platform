# Spec Delta

## ADDED Requirements

### Requirement: 显式首页导航返回分类根页

选择“游戏 → 首页” SHALL 显示分类卡片首页，即使当前已经处于某分类内且顶层仍为首页。进入分类 SHALL 正常展示该分类游戏；仅打开/关闭导航菜单或从编辑器正常返回 SHALL 保留原分类上下文。显式导航 SHALL 继续遵守未保存编辑的离开保护，取消离开不得改变当前页面。

#### Scenario: 从分类内选择首页
- **WHEN** 用户打开任一分类后再次点击“游戏 → 首页”
- **THEN** 直接回到分类卡片列表，分类详情和分类游戏选择器退出

#### Scenario: 连续进入分类并返回首页
- **WHEN** 用户多次进入相同或不同分类后选择首页
- **THEN** 每次都能正常进入分类并回到分类根页，不要求先切换到游戏列表

#### Scenario: 仅关闭菜单或正常编辑返回
- **WHEN** 用户只展开并关闭游戏菜单，或从分类游戏编辑器正常返回目录
- **THEN** 原分类仍保留；显式选择首页后才回到分类根页

#### Scenario: 编辑离开被取消
- **WHEN** 用户在未保存编辑时选择首页后取消离开
- **THEN** 编辑页面及未保存内容保留，不执行首页导航重置
