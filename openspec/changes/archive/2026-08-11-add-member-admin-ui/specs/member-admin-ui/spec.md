## ADDED Requirements

### Requirement: 管理端信息架构与视觉层级
系统 SHALL 为 `member-admin` 提供“总览、房间、会员、记录、排行、系统设置”六个一级入口，并使用统一的明亮液态玻璃拟态设计语言呈现导航、内容容器、状态和操作反馈。

#### Scenario: 在一级功能间导航
- **WHEN** 管理员选择任意一级入口
- **THEN** 系统突出显示当前入口并在统一壳层内展示对应内容
- **AND** 其他一级功能仍可直接到达

#### Scenario: 在窄屏使用管理端
- **WHEN** 可视区域不足以展示完整侧边导航和多列表格
- **THEN** 系统将导航折叠并让卡片、表单和数据内容以可操作的窄屏布局呈现

### Requirement: 运营总览
系统 SHALL 在总览页展示总会员数、当日新增会员、当日发卡次数、当日收款金额和房间状态概况，并清楚标识这些数据的统计语义。

#### Scenario: 查看当日经营概况
- **WHEN** 管理员进入总览页
- **THEN** 系统以易扫描的统计卡展示四项核心指标
- **AND** 同屏展示空闲、游戏中及异常房间的数量或摘要

### Requirement: IC 手环有效使用时长设置
系统 SHALL 提供以分钟为单位的 IC 手环有效时长设置 UI，并明确说明激活、计时起点和未开始游戏时不生效的规则。

#### Scenario: 设置六十分钟有效时长
- **WHEN** 管理员输入 `60` 并执行保存
- **THEN** 系统在当前 UI 状态中显示有效时长为 60 分钟并给出保存反馈
- **AND** 页面说明自助系统激活后可见 60 分钟有效时长
- **AND** 页面说明游戏时长从游戏系统首次刷卡后开始计算，游戏未开始则不计时

#### Scenario: 输入无效时长
- **WHEN** 管理员输入空值、非整数或超出界面允许范围的数值
- **THEN** 系统阻止保存并在字段附近显示可理解的校验提示

### Requirement: 房间管理与状态监控
系统 SHALL 以房间卡片或等效的高辨识布局展示房间名称、空闲或游戏中状态、游戏剩余时间，并允许管理员通过 UI 修改房间名称。

#### Scenario: 扫描全部房间状态
- **WHEN** 管理员进入房间页
- **THEN** 系统同时展示所有模拟房间及其状态
- **AND** 游戏中的房间突出显示剩余时间，空闲房间不显示误导性的倒计时

#### Scenario: 修改房间名称
- **WHEN** 管理员为某房间输入合法的新名称并确认
- **THEN** 系统在当前 UI 状态中更新房间名称并显示成功反馈

### Requirement: 房间临时数据
系统 SHALL 为房间提供实时积分、实时排名、游戏状态和硬件临时状态的查看界面，并明确标注这些数据断电不保存。

#### Scenario: 查看游戏中房间详情
- **WHEN** 管理员打开一个游戏中房间的详情
- **THEN** 系统展示玩家实时积分及排名、当前游戏阶段或状态、硬件在线或异常状态
- **AND** 系统显示“临时数据，断电不保存”提示

#### Scenario: 查看硬件异常
- **WHEN** 模拟房间存在离线或异常硬件
- **THEN** 系统使用图标、文字和语义色共同标识异常设备
- **AND** 不将异常仅通过颜色表达

### Requirement: 会员查询与资料维护
系统 SHALL 提供会员新增、查询、详情、编辑和删除的完整 UI 流程，会员信息 SHALL 覆盖会员账号、头像、联系方式、充值金额、手环时长和身份 ID。

#### Scenario: 查询会员
- **WHEN** 管理员按账号、联系方式或身份 ID 输入查询条件
- **THEN** 系统筛选模拟会员列表并展示匹配结果或清晰的空状态

#### Scenario: 新增或编辑会员
- **WHEN** 管理员打开新增或编辑表单
- **THEN** 系统展示会员资料字段、必填标记和格式校验
- **AND** 合法提交后更新当前 UI 状态并显示成功反馈

#### Scenario: 删除会员
- **WHEN** 管理员执行会员删除操作
- **THEN** 系统先展示包含会员识别信息的二次确认
- **AND** 仅在管理员确认后从当前模拟列表中移除该会员

### Requirement: 会员充值交互
系统 SHALL 提供会员充值 UI，展示当前会员、当前余额或累计充值金额、充值金额输入和结果反馈，同时明确该操作不产生真实资金交易。

#### Scenario: 提交模拟充值
- **WHEN** 管理员为选定会员输入合法的正数金额并确认
- **THEN** 系统展示模拟充值成功反馈并更新当前 UI 中的金额
- **AND** 界面明确标注本 change 未接入真实支付或持久化

#### Scenario: 提交无效充值金额
- **WHEN** 管理员输入零、负数或非数字金额
- **THEN** 系统阻止提交并解释金额要求

### Requirement: 记录查询
系统 SHALL 分别展示发卡记录、游玩记录和交易记录，并为每类记录提供符合其数据语义的搜索、筛选、分页或详情 UI。

#### Scenario: 查看发卡记录
- **WHEN** 管理员切换到发卡记录
- **THEN** 系统展示 IC 手环标识、关联会员、发卡或激活时间、有效时长和状态等发卡信息

#### Scenario: 查看游玩记录
- **WHEN** 管理员切换到游玩记录
- **THEN** 系统展示会员或手环、游玩房间、积分、游戏开始时间和结束时间

#### Scenario: 查看交易记录
- **WHEN** 管理员切换到交易记录
- **THEN** 系统展示关联会员、充值金额、交易时间、流水标识和状态

### Requirement: 会员与游戏数据视图
系统 SHALL 提供会员数据和游戏数据视图；会员数据 SHALL 覆盖会员账号、头像、联系方式、充值金额、手环时长和身份 ID，游戏数据 SHALL 覆盖游戏列表、关卡配置、生命值、积分规则、素材路径和组件信息。

#### Scenario: 查看会员数据详情
- **WHEN** 管理员从会员数据列表打开一条记录
- **THEN** 系统在详情区域分组展示该会员的全部规定字段

#### Scenario: 查看游戏配置详情
- **WHEN** 管理员从游戏列表打开一个游戏
- **THEN** 系统展示其关卡配置、生命值、积分规则、素材路径和组件信息
- **AND** 长路径或复杂配置不会破坏页面布局

### Requirement: 副屏积分排行
系统 SHALL 提供日、月、年度积分排行榜切换，并提供面向电视副屏的预览或展示模式，不暗示已经连接真实电视。

#### Scenario: 切换榜单周期
- **WHEN** 管理员在日榜、月榜和年榜之间切换
- **THEN** 系统更新榜单标题、周期标识、名次、会员信息和积分

#### Scenario: 预览电视副屏
- **WHEN** 管理员进入副屏预览或展示模式
- **THEN** 系统以适合远距离观看的字号和层级突出前三名及其他名次
- **AND** 页面清楚表明当前为 UI 预览而非真实设备连接状态

### Requirement: 功能开关设置
系统 SHALL 在系统设置中提供各类功能开关，展示开关名称、用途、当前状态和变更反馈。

#### Scenario: 切换功能状态
- **WHEN** 管理员启用或关闭一个模拟功能开关
- **THEN** 系统立即在当前 UI 状态中反映新状态并显示反馈
- **AND** 对可能影响主要流程的开关提供确认或影响说明

### Requirement: 数据上传设置
系统 SHALL 提供联网与数据上传设置 UI，支持选择指定邮箱或服务器作为目标，配置目标地址、自动上传开关，并展示连接状态、最近上传结果和测试操作。

#### Scenario: 配置邮箱上传目标
- **WHEN** 管理员选择邮箱并输入格式合法的地址
- **THEN** 系统显示邮箱目标的配置摘要并允许执行模拟测试

#### Scenario: 配置服务器上传目标
- **WHEN** 管理员选择服务器并输入格式合法的地址
- **THEN** 系统显示服务器目标的配置摘要并允许执行模拟测试

#### Scenario: 在离线状态查看上传设置
- **WHEN** UI 模拟为未连接互联网
- **THEN** 系统显示离线状态并禁用或解释当前不可用的测试操作
- **AND** 不声称数据已经发送

### Requirement: 仅 UI 的模拟边界
系统 MUST 使用本地模拟数据和前端内存状态完成本 change 的全部展示与交互，且 SHALL 在涉及充值、硬件、实时数据、副屏和上传的区域给出不误导用户的演示说明。

#### Scenario: 刷新管理端
- **WHEN** 管理员刷新页面
- **THEN** 系统可以恢复预置演示数据
- **AND** 不要求此前的新增、编辑、充值、开关或上传模拟结果被持久保存

#### Scenario: 执行外部集成相关操作
- **WHEN** 管理员点击硬件、电视或上传相关测试操作
- **THEN** 系统只呈现模拟状态和反馈
- **AND** 不发起真实资金交易、硬件控制、邮件发送或服务器数据上传
