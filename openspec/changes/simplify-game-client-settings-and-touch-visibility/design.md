## Context

范围与动机见 `proposal.md`。配置页目前最大宽 900px、字段/分组最大宽 620px，标签与控件分行；调试工具左侧固定 312px，右侧日志占剩余空间。调试助手有配置/布线/调试三个子页，默认进入配置。

打包生成的 `conf.json`、前端调试草稿和 Java 配置默认线序仍为 RGB。布线生成已有稳定枚举，本次只改中文显示。

游戏已经用 `game.child_mode_visible` 保存逐游戏标记，`/games/manageable` 返回管理目录，`/games/playable` 的过滤和启动校验依赖 `MemberPlatformChildMode`。Touch 监听运行状态中的门店 `childMode` 刷新列表。游戏元数据通过现有 PATCH + Electron IPC 更新，现有主进程已具备跨窗口通知方式。

## Goals / Non-Goals

**Goals:** 用局部模板/CSS及现有字段/IPC完成精简；让触屏显示独立、可恢复、保存后跨窗口立即生效；新默认硬件配置一致，旧手动配置不被覆盖。

**Non-Goals:** 不引入路由、通用表单、权限/可见性策略框架或新事件总线；不新增数据库字段/迁移、SDK 报文格式、轮询服务；不取消已排队的游戏、不终止正在游玩的会员；不修改会员管理端/自助注册端产品代码。

## Decisions

### 1. 明确移除副标题的边界

逐页盘点主页面、编辑器及配置弹窗的标题区域，删除主标题旁仅作英文对照或装饰介绍的 subtitle/kicker 元素，而非用全局 CSS 隐藏所有 `p`/`small`。游戏列表选中分类名、资源名称/路径、统计计数、运行状态、字段说明、校验和错误不算装饰副标题，保留。Touch/副屏的待机标题、玩法提示和动画不改。

不删除翻译 key 或历史语言数据，避免扩大到语言架构升级；新增/改名文案仍走现有本地化流程。相比只清除英文文案，各语言均去掉同一装饰元素，切换语言不会再出现重复副标题。

### 2. 配置页拓宽、字段横排，端口仅隐藏

去掉 900/620px 的局部固定上限，利用主工作区可用宽度，采用标签列 + 可伸缩控件列；数值与单位、图片选择按钮与当前文件说明视为同一个控件组。帮助/错误留在控件下方。宽屏同行、窄屏换行，保留输入关联、焦点、校验与保存机制，不把按钮拉高填充空间。

端口控件从模板移除；新配置缺省仍为 8090。**只隐藏 UI，不强制重写旧配置中的有效非默认端口**，防止已部署的自定义地址失联；IP 保存、测试连接、后台启动及重连均读取同一持久化端口。保留端口字段/API兼容性，不删除底层配置能力。

### 3. 硬件助手精简入口，默认 GRB 与布局局部调整

移除配置子 Tab 与组件挂载，默认进入布线工具，保留调试工具。不删除底层生成/加载配置 API、`conf.json` 加载、自动网卡映射和外部手动维护能力；移除页面不能让首次启动依赖点击隐藏页初始化。

将打包默认配置、调试草稿、IPC 缺省值和后端配置缺省线序统一为 GRB，显式 RGB/RBG 等有效配置保持原值；非法显式配置仍沿用既有校验，不偷偷当作 GRB。保持默认 16×36、折返行布线及 TCP 3003，不借此改变其他网络参数。布线中文映射更新，内部枚举与算法不变。

调试工具用响应式两列扩大操作台、压缩日志；参考桌面操作台约 45%、日志约 55%，允许按内容微调。操作标签与控件同行、X/Y各自可读，错误与搜索结果仍可展示。日志长十六进制内容在日志内部滚动/换行，不撑大页面；保留捕获状态、时间、方向、类型、完整内容、展开/收起和清除。

### 4. 触屏显示复用原字段，不再由门店总开关决定

保持数据库列与请求/响应字段 `childModeVisible`，仅 UI 文案改为“触屏显示”，避免 schema 迁移、导入导出与旧元数据调用失效。true/缺省/null 按显示，false 按不显示；不批量修改历史值。提示文案说明影响玩家选择界面，不再提儿童模式。

`/games/playable` 按逐游戏标记直接过滤，适用于所有使用 Touch 的启动方式（触屏/手环/投币）与调试/游戏运行模式；`/games/manageable` 始终保留关闭显示的游戏。游戏首页分类内管理列表也仍可编辑这些游戏，排序及其他分类的槽位不变。

移除新游戏端目录和启动链路对会员管理端 `childMode` 的行为依赖，旧消息可忽略，不影响连接握手和其他事件。**触屏显示是展示配置，不是游戏启动权限**：移除遗留儿童模式启动拦截，编辑器的指定游戏调试仍可启动隐藏游戏；已排队的任务按原规则继续，不因显示开关取消。会员管理端旧开关及其对旧客户端的协议保留，本 Change 不顺带删除它。

### 5. 即点即保存与跨窗口即时更新

在游戏信息弹窗切换触屏显示时，只 PATCH 该布尔字段；保存中暂时禁用重复切换，失败恢复原值并显示错误。不顺带保存尚未确认的名称/封面/分类草稿；这些字段仍由原保存/取消控制。已成功单独保存的开关不因稍后取消其他草稿而撤销。

成功后用现有 Electron 主进程跨窗口 IPC 通知目录变化，不新增后端目录版本表/计数器或额外轮询。已打开的 Touch 游戏选择/排队选择刷新可玩目录；后台窗口或之后才打开的窗口重新读取数据库。刷新失败保留最后成功的列表并提示重试，不把请求失败当成“游戏已隐藏”来取消会话。

若尚未运行的当前选择确实从最新列表消失，走现有取消准备/释放手环访问流程，避免遗留准备会话；正在 RUNNING 的游戏、已入队任务和积分/扣时不变。取消无关草稿、通知监听注册/卸载及事件重复均补回归测试，不用每帧重新请求目录。

## Risks / Trade-offs

- [历史 false 值以前只在儿童模式开启时隐藏，现在直接隐藏] → 不擅自改值；说明升级行为，管理列表可随时重新开启，并覆盖新旧/null 数据测试。
- [隐藏端口导致旧自定义部署连接错误] → 保留原有效端口；测试健康检查、房间连接和会员请求读取相同地址。
- [新默认 GRB 与已配置 RGB 混淆] → 只改变默认/缺省；打包隔离检查新 conf 为 GRB，已有显式配置不覆盖，协议测试验证通道排列而不是简单改所有断言。
- [立即开关保存带上其他草稿或失败假成功] → 最小布尔 PATCH、禁重复提交、失败回滚，测试取消名称修改与开关的独立性。
- [目录刷新影响运行或误取消手环] → 只有确认最新目录成功且 PREPARING 选择被移除才取消；队列选择重置不结束当前局，测试访问释放、正常结算和后续排队。
- [标题删除、日志收窄损失必要提示] → 用明确入口清单、三种窗口截图、完整日志展开与输入交互测试验收，不全局隐藏文本。

## Migration Plan

先补隔离数据与真实组件/IPC测试，再实施前后端局部修改。无数据库迁移，旧 false 直接继承为触屏不显示，未设置默认显示；旧自定义端口、硬件显式线序及资源不变。更新中文说明，运行全量回归、i18n 与规格校验，再更新游戏端原位置 win-unpacked/ZIP 并做隔离冒烟；不读取人工数据库、不连接真实硬件。

回滚应用版本即可恢复旧可见性解释，原字段、API、游戏资源保持兼容；不回滚或删除用户数据库。
