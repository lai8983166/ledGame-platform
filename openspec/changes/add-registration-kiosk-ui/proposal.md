## Why

现有 `registration-kiosk` 只有占位入口，无法演示玩家从手机号确认到手环激活完成的完整自助流程。需要基于提供的 7 张参考图建立适合横屏触控设备的 UI 基线，让流程、软键盘、头像选择和刷卡反馈可以在不接入真实设备的情况下完整操作。

## What Changes

- 新增自助机首页，按参考图呈现品牌标题、`Activate Wristband` 主入口和 `Player Info Query` 次要入口；本 change 仅实现手环激活流程。
- 新增手机号确认界面，输入框获得焦点时弹出屏幕数字键盘，可完成输入、删除、清空、关闭与确认。
- 新增注册资料界面，包含 Avatar、Name、Phone Number、Birthday 和 Gender 字段；输入型字段获得焦点时显示适合其内容的软键盘。
- 新增头像来源选择面板，提供 `Set from Library` 与 `Take Photo` 两个入口；本 change 仅实现内置头像库选择，拍照入口只展示未接入提示。
- 新增内置头像库界面，以触控友好的网格展示预置头像，支持选择、确认和取消，并将选择结果回填到注册资料。
- 新增 `Swipe Wristband` 界面，展示玩家资料摘要、手环感应区域和等待状态，并提供仅用于 UI 演示的模拟刷卡成功操作。
- 新增激活成功界面，展示成功状态、所选头像、玩家名称与 60 分钟有效时长；点击 `Return Home` 清空当前演示会话并回到首页。
- 整体采用参考图所示的蓝青色科技感横屏触控风格，优化文字对比、界面层次、触控尺寸、状态反馈和 16:9 自助机适配。
- 本 change **只做界面**：所有资料仅保存在当前前端内存，不实现手机号查询、会员注册持久化、真实相机、真实读卡器、IC 卡写入、后端请求或硬件通信。

## Capabilities

### New Capabilities

- `registration-kiosk-ui`: 自助机手环激活 UI 的首页、手机号输入、注册资料、软键盘、头像选择、模拟刷卡和激活成功完整流程。

### Modified Capabilities

- 无。

## Impact

- 主要影响 `apps/registration-kiosk` 的 Vue 页面结构、样式、前端状态、预置头像素材与本地模拟交互。
- 不要求修改服务端、API client、会员数据或硬件协议。
- 不新增真实外部系统依赖；相机、读卡器和激活结果均以明确标识的 UI 演示状态表达。
