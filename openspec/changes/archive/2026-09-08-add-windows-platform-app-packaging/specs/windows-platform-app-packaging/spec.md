## ADDED Requirements

### Requirement: 会员管理端具有自包含 Windows 交付包
系统 SHALL 生成可在未预装项目依赖和系统 Java 的 Windows 机器上运行的会员管理端目录包与便携 ZIP，并在包内携带 Electron UI、会员管理后端可执行 JAR 和精简 JRE。

#### Scenario: 干净 Windows 环境启动会员管理端
- **WHEN** 操作员解压会员管理端便携包并启动应用，且机器未安装系统 Java、Maven、Node.js 或 pnpm
- **THEN** 应用使用包内 JRE 拉起包内后端并打开会员管理 UI
- **AND** UI 在后端健康检查成功后进入可操作状态

#### Scenario: 内置后端启动失败
- **WHEN** 包内后端未能在规定时间内通过健康检查
- **THEN** 会员管理 UI 仍可打开本地启动诊断界面
- **AND** 界面显示稳定错误、后端退出状态和日志目录，而不是空白页或无限等待

### Requirement: 自助注册端具有独立 Windows 交付包
系统 SHALL 生成不携带会员数据库、会员管理后端或 JRE 的自助注册端目录包与便携 ZIP，并由其 Electron 主进程连接指定会员管理端。

#### Scenario: 启动自助注册端便携包
- **WHEN** 操作员在另一台 Windows 机器启动自助注册端
- **THEN** 应用打开本地运维启动页
- **AND** 在尚未成功连接会员管理端前不启动面向顾客的注册流程窗口

### Requirement: 运行数据独立于应用安装目录
会员管理端和自助注册端 SHALL 将可变配置、SQLite、日志和其他运行数据写入各自的 Electron 用户数据目录，不得写入或依赖只读安装资源目录。

#### Scenario: 替换应用包后保留数据
- **WHEN** 操作员关闭应用并用同产品的新版本程序文件替换旧版本
- **THEN** 已保存的连接配置和会员管理端 SQLite 数据保持可用
- **AND** 新版本不会以包内种子文件覆盖现有数据库

### Requirement: 桌面进程拥有其子进程生命周期
会员管理端 Electron 主进程 SHALL 以显式参数启动包内后端、保留有限日志、监测退出并在应用退出时只终止自己创建的后端进程树。

#### Scenario: 正常退出会员管理应用
- **WHEN** 操作员正常退出会员管理端 Electron 应用
- **THEN** 应用等待或终止本次运行所创建的后端进程
- **AND** 不终止其他 Java、Electron 或会员管理端实例之外的进程

#### Scenario: 后端意外退出
- **WHEN** Electron 仍在运行而受管后端进程意外退出
- **THEN** UI 切换为不可用状态并展示可定位诊断
- **AND** 操作员可在不重装应用的情况下重新尝试启动后端

### Requirement: 构建产物具有自动化冒烟证据
构建流程 SHALL 提供分别生成两个应用目录包和便携 ZIP 的命令，并对目录包执行无需真实门店数据或固定端口的启动冒烟测试。

#### Scenario: 构建会员管理端与自助注册端
- **WHEN** 发布人员在满足构建依赖的仓库中执行平台桌面打包命令
- **THEN** 输出目录包含两个产品名和应用 ID 不冲突的 Windows 目录包与 ZIP
- **AND** 冒烟测试证明两个目录包均可启动到各自的本地首页后安全退出
