# 空 MAC 网卡修复验证（2026-10-13）

根因：运行时快照允许 Java 返回空 MAC，UDP 构造时却要求 MAC 必填。此规则在此前代码中已存在；调试入口立即搜索暴露了该边界。UDP 按本机 IPv4 绑定，MAC 仅为定位回退，无需强制填写。移除该项必填，保留 IP、ID、前缀等校验，不修改协议。

- 63 项相关后端测试通过：SDK、配置、网卡解析、运行时准备和调试接口。补充 null MAC 无回复正常超时用例，已有多回复搜索用例改用空字符串 MAC，验证两种输入。
- 11 组真实 Vue 界面测试通过：无设备弹窗两秒关闭/手动关闭、无硬件模拟、网卡及端口错误中文提示；构建和 i18n 检查通过。
- 打包 EXE 隔离数据冒烟通过，包含 Simple 和两种尺寸 Rank 调试及后端退出。
- 原 release/win-unpacked 与 LED Game-0.1.0-win.zip 已更新，916 个文件逐项长度和 SHA-256 一致。
- 未连接真实控制器，未宣称完成实际硬件收发验收；未修改本机游戏数据库或网卡配置。
