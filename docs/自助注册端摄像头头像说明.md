# 自助注册端摄像头头像

自助注册端的头像来源有两种：离线头像库和本机摄像头。摄像头功能只使用 Windows 能识别的本机视频设备，包括内置摄像头和标准 USB UVC 摄像头；不支持通过 IP 地址接入网络摄像头。

在注册资料页点击头像，选择“设备摄像头”后可以选择摄像头、查看实时预览、拍摄、重拍、确认使用或取消。照片会在客户端裁成正方形，缩放到不超过 512×512，并限制在 256 KB 以内。注册请求完成、取消或失败后，客户端都会清理临时照片数据。

摄像头不存在、权限被 Windows 拒绝、被其他程序占用或在预览中断开时，界面会给出对应提示；这些情况不会阻止注册，返回头像来源选择后仍可使用离线头像库。

会员管理端不会把照片明文写入 SQLite 或日志。确认的照片以随机标识关联，并使用现有数据保护密钥加密保存在数据库目录的 `avatars` 文件夹中。数据库备份会同时保存加密头像文件和校验清单，导入时必须通过校验才能替换当前数据库与头像文件。

系统只保存和展示头像，不进行人脸识别、年龄判断或其他生物特征分析。
