# 会员积分与兑换

- **排名积分**：已结算游戏累计获得的积分。排行榜、管理端副屏保持原有算法与日/月/年口径。
- **剩余积分**：排名积分减去已经扣减的积分，用于兑换。没有扣减记录的原有会员，两种积分相同。

## 如何操作

1. 在会员管理列表找到会员，点击剩余积分旁的“扣减积分”。
2. 输入正整数积分和原因，确认后才扣减；取消不做任何修改，余额不足不能扣减。
3. 点击会员进入详情，再点“积分扣减记录”，查看最近 100 条记录的扣减值、前后积分、原因、时间和操作员。

出厂账号、店长、店员均沿用会员管理权限操作。扣减不影响账户时长、手环计时、收款及游戏记录。扣减后的正常游戏结算会同时增加剩余积分和排名积分。

自助注册端的会员信息查询可查看两种积分，但不能扣减。记录与数据中的会员 CSV 也区分两种积分；数据库全量备份和自动备份包含扣减记录。

## 接口兼容与防重复

- `GET /api/members`：新增 `remainingPoints`、`rankingPoints`；旧 `pointsTotal` 仍表示排名积分。
- `GET /api/player-info`：新增 `points.remaining`、`points.ranking`；旧 `points.total` 仍表示排名积分。手机号、手环两种查询均可用。
- `POST /api/members/{id}/point-deductions`：携带操作员身份，提交 `points`、`reason`、`requestId`。同一请求重试不会重复扣分；同一请求号改变内容会拒绝。
- `GET /api/members/{id}/history`：新增 `pointDeductions`，仅有权限的管理端查询。

扣减记录和余额校验在同一事务内完成；并发不能超扣，写入失败不会留下扣减。升级仅增加记录表和索引，不修改原游戏积分记录。不推断旧外部系统可能发生过的兑换。
