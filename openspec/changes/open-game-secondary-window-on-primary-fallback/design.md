# Design

## Context

现有副屏显示器匹配仅允许非主屏，自动启动在没有外接屏时返回；窗口创建固定全屏。沿用现有副屏页面、状态推送和 IPC，不增加新的设置字段。

## Goals / Non-Goals

- 目标：同一套启动逻辑支持单屏和多屏，单屏关闭后可以从副屏菜单重新打开。
- 非目标：不修改副屏内容、游戏规则、会员管理端副屏或显示器选择的持久化格式。

## Decisions

- 保留严格的外接屏匹配，增加自动目标选择：已保存外接屏、首个外接屏、主屏。单屏回退不持久化为外接屏偏好。
- 主屏窗口在工作区居中，最大 1280×720、且不超过工作区的 80%，保持窗口式；外接屏继续覆盖其完整区域并全屏。拒绝无尺寸的显示目标。
- 单屏状态把主屏作为有效回退目标，以兼容原有“打开副屏”按钮。插入外接显示器时，自动将主屏回退窗口转移至外接屏，保留原有自动打开副屏的能力。
- 不引入独立窗口管理器，只在现有显示器辅助模块增加两个小函数供主进程与测试复用。

## Risks / Trade-offs

- 单屏有两个窗口 → 回退窗口可移动、缩放、关闭，不全屏遮住操作界面。
- 实机无法覆盖所有多屏排列 → 通过单元测试检查负坐标、主屏工作区和已保存选择；打包版隔离启动验证实际窗口。
