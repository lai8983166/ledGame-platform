## Why

游戏端已经支持可选的全局游戏时间，但该时间尚未形成跨玩法、跨界面的统一运行时状态：副屏只能看到个别玩法的局部时间，会员管理端房间管理更是始终显示 `00:00`。门店需要在游戏进行时同时从副屏和房间 Card 准确判断本局剩余时间，并在玩法未限制全局时间时明确看到“无限”。

## What Changes

- 新增与具体玩法无关的游戏计时运行时投影，明确区分有限全局时间与无限时间，并携带可供客户端校准的剩余时间、计时状态和观测时间。
- 游戏副屏统一展示当前局的全局剩余时间：有限时实时倒计时，无限时显示“无限”，暂停时冻结，空闲或结束后不显示误导性倒计时。
- 游戏桌面端在开始、暂停、恢复、结束以及重连快照等关键节点向会员管理端同步计时锚点；不采用每秒跨机器推送倒计时。
- 会员管理端房间 Card 和房间详情读取真实计时状态，在本机按秒刷新有限倒计时，无限模式显示“无限”。
- 为有限、无限、暂停/恢复、结束、重连恢复和旧状态兼容补充后端、前端及跨端契约测试。

## Capabilities

### New Capabilities

- `game-time-presentation`: 定义统一游戏计时运行时契约、关键节点同步，以及游戏副屏和会员管理端房间管理的剩余时间展示行为。

### Modified Capabilities

无。

## Impact

- `F:\project\ledGame-backend`：游戏运行时状态、全局计时投影、生命周期事件和房间长连接上报。
- `F:\project\ledGame`：运行时状态归一化、副屏展示、倒计时格式化与相关测试。
- `F:\project\ledGame-platform`：房间状态 API 类型、会员管理端房间状态映射、本地倒计时展示与验收测试。
- 房间状态 JSON 将新增可选计时字段；为兼容已部署端和旧快照，消费者必须容忍字段缺失，不构成破坏性变更。
